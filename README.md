# "Cartório" com Blockchain

Esse repositório é para o projeto da disciplina SSC0958 Blockchain e Criptomoedas. A proposta é uma aplicação web que simula um sistema de registro de documentos digitais utilizando um Smart Contract (Contrato Inteligente), serviço essencial em cartórios.
